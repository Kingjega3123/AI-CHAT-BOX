
# 🤖 AI Portfolio Chatbot

An interactive **AI-based portfolio chatbot** built using **React.js**.  
This project allows users to explore my portfolio by asking questions about my **skills, projects, education, certificates, and contact information**.

Instead of browsing through a traditional portfolio website, users can interact with a chatbot to learn about my professional background.

---

# 🚀 Features

- 💬 **Interactive Chatbot Interface**
  - Users can ask questions about my portfolio.

- 📂 **Section-Based Navigation**
  - Skills
  - Projects
  - Education
  - Certificates
  - Contact

- 🧠 **Smart Response Logic**
  - The chatbot analyzes user input and returns relevant information.

- 📊 **Resume Data Integration**
  - All chatbot responses are generated from structured resume data.

- 🎯 **Project Specific Queries**
  - Users can ask about specific projects like:
    - Deep Learning Food Classifier
    - Portfolio Website
    - Social Media UI Clone

- 📜 **Certificate Verification**
  - Users can ask whether I have a specific certificate.

- 🎓 **Education Queries**
  - Supports questions like:
    - 10th / SSLC
    - 12th / HSC
    - College
    - Passout year

# ⚙️ Installation

Follow these steps to run the project locally.

### 1️⃣ Clone the repository

```
git clone https://github.com/your-username/ai-portfolio-chatbot.git
```

### 2️⃣ Navigate into the project

```
cd ai-portfolio-chatbot
```

### 3️⃣ Install dependencies

```
npm install
```

### 4️⃣ Install React Router

```
npm install react-router-dom
```

### 5️⃣ Run the project

```
npm start
```

The app will run at:

```
http://localhost:3000
```
